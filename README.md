# Movie Finder Extension

A simple Chrome extension that helps users search movies and find legal streaming options.

## Features

- Search movies by title
- Show movie poster, year, and overview
- Display available streaming providers
- Link to official watch options

## Tech Stack

- Chrome Extension
- JavaScript
- Python
- FastAPI
- TMDB API

## How to Run

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
